---
name: IHTXPlus access
description: The access scope chosen for the bot's raw FFmpeg option command.
---

Anyone who can use the Discord bot may invoke IHTXPlus with raw FFmpeg options.

**Why:** the project owner selected this scope after being told FFmpeg options can access files and network resources available to the bot.

**How to apply:** Keep IHTXPlus available wherever the bot is available. Pass its options directly as process arguments; never execute them through a shell.
